# Sourced Reference Art

This directory holds public-domain period source art kept as **visual reference** for the Forge art pipeline (architecture, costume, ships, material culture of Portuguese Estado da India). Nothing here ships directly.

**Retired pipeline note (2026-08-01):** the previous menu/loading screens were derivatives of two 18th-century Lisbon paintings (`vista-terreiro-paco-xviii.png`, `paco-ribeira-18th-century.jpg`). They were wrong-city/wrong-century for 1580 Melaka and have been deleted along with `tools/create-sourced-screen-art.cjs`; title/loading art is now generated by the Forge (`tools/generate-interim-screens.cjs` interim, title panorama planned in Stage 6). See `docs/RELEASE_NOTES_v0.9.0.md` for the historical record.

## Candidate Additions (reference only)

Keep additions close to 1580-1635, prefer Portuguese Estado da India / Malacca / Goa material, and document source URL plus rights status.
