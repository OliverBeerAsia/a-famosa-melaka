## Follow-up

Clamping only makes coordinates *legal*, not *good*. Crowd paths and night lights were re-anchored by hand onto visible walkable ground / plausible light sources in a manual pass after this codemod ran (milestone M1 "visible city"). Re-running this codemod would overwrite that hand work — it is a one-shot, kept for provenance.
